КАК ПОЛУЧИТЬ APK (бесплатно, без установки Android Studio)

1. Зарегистрируйтесь на github.com (если нет аккаунта).
2. Создайте новый репозиторий (New repository), например "svetlyachok".
3. Нажмите "uploading an existing file" и перетащите ВСЁ содержимое этой папки
   (включая скрытую папку .github). Нажмите Commit changes.
4. Откройте вкладку Actions -> дождитесь зелёной галочки (3-6 минут).
5. Откройте последний запуск -> внизу в Artifacts скачайте "svetlyachok-apk".
6. Внутри архива будет app-debug.apk -> скиньте на телефон и установите
   (разрешите установку из неизвестных источников).
